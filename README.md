# Python CLI Task Manager 

A simple command-line task manager built in Python that allows users to manage tasks efficiently with persistent storage using a JSON file.

---

## Features

- Add new tasks
- View all tasks
- Mark tasks as complete
- Delete tasks
- Saves tasks automatically using a JSON file
- Simple command-line interface (CLI)

---

## Project purpose

This project was created as a way to apply core programming concepts in a practical environment. It focuses on building a working tool that demonstrates how data can be stored, updated and managed through the CLI

---

## Technologies used

- Python
- JSON (data storage)
- File handling
- Modular programming
